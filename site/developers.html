获取与构建

项目仓库：sherlockerX/Nicholasx ↗。本页不会把你转去上游安装包；公开下载状态以产品页为准。

git clone --recurse-submodules https://github.com/sherlockerX/Nicholasx.git
cd Nicholasx

工具链：JDK21、Android SDK36、Build Tools35.0.0、CMake3.22.1、NDK27.2.12479018。完整arm64版本包含PRoot、Alpine rootfs及rclone等依赖，先按仓库原生脚本构建。

# Linux或WSL，先准备原生依赖
bash scripts/android/build-natives.sh

# Windows PowerShell，使用你本机的JDK和SDK路径
$env:JAVA_HOME = '你的JDK21目录'
$env:ANDROID_HOME = '你的Android SDK目录'
./scripts/android/Build-Android.ps1 -Target Check
./scripts/android/Build-Android.ps1 -Target Debug

x86_64隔离包用于界面与数据回归，不代表arm64沙盒功能已经验证。首次构建需要下载依赖；离线构建只适用于本机缓存已齐全的情况。

更多说明见仓库中的docs/android-development.md。脚本通过Gradle Wrapper启动，不要求安装全局Gradle，也不会把本机SDK路径写进源码。

源码地图

Android保留上游结构，业务扩展主要位于android/src/android/app/src/main/java/io/github/nanomuse/。

模块职责先读这里
聊天主要对话、每日点子、回复朗读和工具协作chat/、ui/chat/
待办任务、分组、标签、版本冲突和完成证据todo/TodoStore.kt
专注计时事实、区间统计、沉浸界面和背景focus/FocusStore.kt
生活碎片日记、草稿、任务及专注关联mosaic/MosaicStore.kt
教练课程、训练、证据和对话衔接coach/、ui/coach/
账号边界隔离数据、阻止旧页面跨账号写入account/AccountData.kt

上游的com.openminis.app命名空间与沙盒协议保持兼容。整理代码以清晰入口、边界和测试为先，不用大规模移动文件来制造“整洁”。

参与贡献

从一个具体体验开始：说清遇到的场景、预期、实际结果、版本和复现步骤。附脱敏日志，避免把真实聊天、图片、密钥或个人档案放进公开问题。

  • 功能与Bug：在项目仓库Issue中讨论，再做聚焦的小改动。
  • 涉及待办或专注：验证revision、幂等、账号隔离和中断恢复。
  • 涉及界面：检查深浅主题、大字体、横屏、键盘与返回路径。
  • 涉及文案：同步现有语言资源，说明验证范围。
  • 提交使用DCO签署，保留GPL许可与上游归属。

仓库中的OPEN_SOURCE.md和docs/android-code-map.md提供更完整的入口。独立安全问题先确认仓库的私密报告渠道，不在公开Issue里上传漏洞细节。

数据与模型

任务、专注和生活记录由应用本地存储。模型服务、账号与同步服务取决于你的配置，发送给服务商的请求遵循对应服务条款。本项目不承诺所有功能离线，也不将上游公共服务额度当成这个分支的承诺。

专注背景只保存用户选中文件的本地副本；不会由专注工具交给模型。工具执行仍需要当前对话和账号授权，计时结束不会自动完成待办。

本宣传页不含分析追踪器、广告SDK或远程字体。交互示例只在当前浏览器运行，关闭页面后不保留示例状态。

许可与来源

Nivo Bot是nanoMuse的衍生项目。nanoMuse采用GPL-3.0-or-later；Android底座来自OpenMinis，保留其GPL许可与版权声明。具体适用条件以LICENSE、NOTICE和THIRD_PARTY_NOTICES.md为准。

上游项目：nanoMuse、OpenMinis。本项目不代表上游官方，也不隶属于Meta或其Muse产品。

贡献者可以修改和分发，但需要履行对应许可义务。发布APK时应提供与该安装包一致的对应源码和构建说明。

发布边界

当前重点是Android体验。iOS、桌面与云端代码在仓库中的存在，不等于这个分支已经提供公开可用的跨平台服务。

Android v2.0.0（51）使用专用发行证书。旧Debug签名包不能直接覆盖升级；聊天、教练、待办、专注与附件的跨签名恢复仍需核验，请勿直接卸载旧应用。此次验证包括本地构建、自动测试和包身份检查，不代表所有手机与模型服务均已实测。

python scripts/release/source_audit.py --output source-audit.json

# 只生成独立候选包，不改动原项目、不上传
python scripts/release/prepare_source.py --root . \
  --overlay reviewed-overlay --output Nivo-Bot-source.zip \
  --restore-missing-from-head

扫描只是一层检查，不替代Git历史凭据检查、完整许可审核和新机器构建验证。对外发布前应逐项阅读检查报告。
