Nivo Bot是一个持续维护的开源衍生项目。了解构建方式、模块边界与每次发行对应的源码。

从源码开始

打开sherlockerX/Nivo-Bot仓库 ↗

git clone --recurse-submodules https://github.com/sherlockerX/Nivo-Bot.git
cd Nivo-Bot
bash scripts/android/build-natives.sh
cd android/src/android
bash gradlew :app:assembleDebug --console=plain --no-daemon

使用JDK21、Android SDK36、NDK27.2.12479018和CMake3.22.1。完整工具链与Windows入口以仓库文档为准。

Android构建与签名文档 ↗ · GitHub自动打包 ↗

模块有各自的职责

入口职责
chat / ui/chat主要聊天、工具协作、回复朗读
todo任务、分组、标签、版本冲突与完成证据
focus计时事实、全屏恢复、背景和统计
mosaic生活碎片、草稿和任务／专注关联
coach课程、每日练习、证据与回访

Android扩展主要位于io.github.nanomuse命名空间。上游包名、沙盒协议与许可继续保留。

给之后的版本留好位置

下载中心由版本清单驱动。每个发行记录保存平台、渠道、版本、架构、日期、安装地址、SHA256、对应源码和说明页。加入新版本即可继续显示历史版本；只有实际可用的文件会显示下载入口。

iOS目前单独显示尚未公开发布。未来应按实际分发渠道增加记录，而不是让Android和iOS共用一个安装按钮。
