第一次连接模型。

先理解几个设置，再选择你自己的服务商。

第一次接入？

先走通文字对话，
其他能力慢慢加。

App里通常从“设置 → 模型”或“添加AI服务商”进入。优先选对应厂商预置；名称会随版本略有差异。

  1. 01去厂商控制台准备账号、额度与Key。
  2. 02在App选择协议，填写基础URL和Key。
  3. 03刷新模型或手动添加精确模型ID。
  4. 04在设置中选择“对话”模型，发一条短问候。

API Key是凭证

只填App的服务商设置。这里不会要求你输入Key，也不会替你测试真实请求。

Base URL是服务入口

不是控制台网址，也通常不是完整的/chat/completions操作地址。

模型ID是准确名字

优先从平台列表复制，厂商前缀、大小写和日期后缀都可能有意义。

BEFORE YOU CONNECT

四个设置，
先弄清它们的关系。

对话、操作屏幕、生成图片、生成视频要全部配置吗？

不需要。先选“对话”模型。操作屏幕需要视觉能力，生成图片和视频需要专用模型及App已适配的接口，不能用普通文本模型代替。

为什么自动追加/v1会影响连接？

App会根据开关拼接地址。基础URL已经含/v1时不要再追加；智谱的/v4、方舟的/v3和Gemini原生/v1beta也不能再追加。每篇教程都给出字段和开关的对应值。

聊天会员、API余额、Coding套餐是一回事吗？

通常分别管理。订阅能否用于第三方App、可用端点及客户端范围，须以具体产品条款为准。不要把编程套餐当作通用无限聊天额度。

没有模型列表怎么办？

有些服务不支持列举模型。在App服务商详情里使用“添加自定义模型”，填写控制台给出的精确ID；普通聊天成功后再验证流式和工具。

朗读和语音输入也要买模型服务吗？

回复可使用手机系统TTS。语音输入可以沿用手机输入法；专门的实时语音服务是另一项可选配置，不是文字聊天的前提。

这些教程是否代表全部厂商都经过实机验证？

教程根据当前App源码和官方资料整理，核对日期为2026-11-13；没有使用你的Key逐一请求所有厂商。模型、计费和账号可用性以实际控制台为准。
