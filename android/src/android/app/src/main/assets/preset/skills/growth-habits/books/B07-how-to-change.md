# B07 How to Change（凯蒂·米尔克曼，2021）
层级：补充；覆盖子能力：A、B、C、F；简体中文版未核实，繁体版《零阻力改變》

## 一句话主旨
改变失败往往不是因为缺意志力，而是撞上了某种特定的内在障碍。先诊断是哪种障碍，再挑匹配的工具。

## 可迁移的模型
- 障碍匹配：书按开始难、冲动、拖延、遗忘、惰性、缺乏信心、从众分章给工具（章节划分凭记忆）；失败时先问是哪种障碍；子能力 A、C
- 新起点效应：新年、生日、学期初这类时间节点让人更愿意启动改变；节点带来的动力很短，要马上接上习惯设计；子能力 C
- 诱惑捆绑：只在做该做的事时享受某个喜欢的东西；别的时候也能享受到，捆绑就失效；子能力 B、C
- 承诺装置：提前给自己设限制或代价；太严的承诺会让人失败一次就彻底放弃；子能力 C、F
- 有限弹性：留出有限的豁免机会，比要求完美执行更能坚持（凭记忆）；豁免太多就等于没有规则；子能力 B

## 可以直接练的做法
- 情景：你连续三周没做到"每周跑步三次"，分别假设原因是忘了、讨厌、太累，各配一个工具。
- 行动：本周给一项讨厌的任务（整理文献、报销）做一次诱惑捆绑，记录完成次数。

## 常见误读
把书当技巧清单全部照搬。作者的核心是先诊断再选工具；她自己的大型研究也显示，多数干预的效果很短暂。
