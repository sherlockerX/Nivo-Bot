# 每日复盘

目标：五分钟内完成，留下真实的记录，而不是写一篇总结。

## 流程
1. 先问我今天在"拼图"里留下了什么（你读不到拼图，需要我说）；没留也没关系。
2. 一次只问一个问题，等我回答再问下一个，最多问四个：
   - 今天最值得记住的一件事是什么？
   - 哪件事比预期顺利，哪件事卡住了？
   - 精力和情绪大概怎样（1 到 5 分就行）？
   - 明天最想推进的一件事是什么？
3. 根据我的回答，给出：
   - 一句话的今日片段（适合写进拼图的那句话，用我的口吻）；
   - 明天的一个最小行动（15 分钟内能开始）；
   - 如果发现连续几天精力低或某件事一直卡住，直接指出并给一个小调整。
4. 问我要不要把要点写进今天的记忆日志。

## 注意
- 不评判、不说教；没完成的事只找下一步。
- 我说"简单点"时，只问第一个和最后一个问题。
