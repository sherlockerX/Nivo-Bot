# B02 English Collocations in Use（McCarthy 与 O'Dell，中级 2005，高级 2008）
层级：核心；覆盖子能力：A、G、E；无简体中文版（未核实）

## 一句话主旨
地道与否主要取决于词和词的惯常组合。按主题和功能成组学搭配，比单背生词更能直接改善输出。

## 可迁移的模型
- 搭配强度：make a decision 这类强搭配接近固定，要整体记，弱搭配靠理解；写作时先确认强搭配；领域术语的搭配书里没有，要查论文语料；子能力 A
- 节点词辐射：围绕高频名词收集"动词加名词""形容词加名词"；写作前先查核心名词常配哪些动词；硬塞罕见搭配会显得做作；子能力 A、B
- 语域切换：同一个意思有口语和书面两套搭配，比如 get better 和 improve markedly；邮件、论文、聊天分开用；书里的语域标注较粗；子能力 A、D、G
- 中式搭配纠偏：直译容易出错，比如 learn knowledge 应改为 acquire knowledge；建一份个人错误清单；本书不专为中文母语者写，要自己积累；子能力 A
- 主题单元：每单元一个情境，比如研究、观点、社交；先选和当周任务对口的单元；看得懂不等于说得出；子能力 A、G

## 可以直接练的做法
- 每天从当天读的论文里摘 5 个"动词加名词"搭配，用语音复述摘要 1 分钟，把它们全部用上。
- 检查自己最近的一封英文邮件，标出可疑的搭配，查语料后替换。

## 常见误读
以为做完一本练习就自然地道了。搭配要在输出里被多次提取，才会变成主动能力。
