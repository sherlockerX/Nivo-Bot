# B09 原则之外（The Fund，罗布·科普兰，2023）
层级：对照；覆盖子能力：C、G、H；浙江人民出版社 2024，张晚晴译

## 一句话主旨
一位财经记者基于大量访谈，写原则在桥水实际运行时的另一面：透明和打分可能沦为控制手段，对外宣称的系统化决策和实际上由少数人拍板之间存在落差。书中部分描述被桥水和达利欧否认。

## 可迁移的模型
- 宣称与运行的落差：评价一套原则，要看它在权力不对等时怎么执行；用来审视你所在组织的规则；把个别人的经历当成所有人的经历就错了；子能力 C、H
- 透明的方向：录音和公开打分如果只针对下级、不针对上级，透明就变成了监视；设计反馈机制时先查清谁能看到谁；双方对等互评时不成问题；子能力 H
- 谁来定可信度：可信度加权需要独立的记分，否则会被最有权的人定义；用来检验 B01 的同名模型；有公开、可核对记录的领域里问题较小；子能力 G
- 读批评的方法：分清实名证词、匿名转述和作者解读，再去看当事方的回应；当事方不回应时只能标为未证实；子能力 D、G
- 原则变教义：原则只被背诵引用而不被检验时，就从工具变成了教义；新原则还在试用、没固化时风险小；子能力 C

## 可以直接练的做法
- 情景：读一段书中的指控和桥水的回应，把每一句标成事实、解读或未证实。
- 行动：给自己的原则清单做一次权力测试：假如别人拿这条原则来要求你，你能接受吗？至少修改一条。

## 常见误读
把这本书当成对达利欧方法的证伪。它针对的是一家公司里的执行和人；书中部分事件遭当事方否认；书里的个人反思方法并不因此失效。
