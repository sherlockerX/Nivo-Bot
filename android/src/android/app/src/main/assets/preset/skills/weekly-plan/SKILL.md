# 周计划

## 流程
1. 收集：请我列出这周的事（研究、课程、自媒体、生活、健康），以及已经固定的时间（组会、课程、约定）。
2. 回顾上周：哪些完成了，哪些拖着，原因是什么（一句话即可）。
3. 排序：每件事标出重要程度和截止时间；最多选 3 件本周重点。
4. 取舍：总时间放不下时，明确说砍掉或推迟什么，不再叠加。
5. 落到每天：每个重点拆成每天能开始的最小行动；给每天留出空白和休息时间。
6. 输出一张简洁的周表：周一到周日，每天 1 到 3 项。

## 注意
- 涉及时间投入的新计划，先对照已有安排，有冲突就给取舍，而不是再加一层。
- 方案要能直接照着执行，比面面俱到更重要。
- 问我要不要把本周重点写进记忆，周末复盘时对照。
