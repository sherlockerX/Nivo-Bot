# B10 国家的视角（Seeing Like a State，詹姆斯·斯科特，1998）
层级：对照；覆盖子能力：H、D、B；社会科学文献出版社，王晓毅译（已核实 2019 年版，2004 年初版未核实）

## 一句话主旨
为了便于管理，把复杂的现实简化成可登记、可统计的样子，再照着这张简化图大规模改造社会和自然，常常会因为忽视本地实践知识而失败。

## 可迁移的模型
- 可读性：管理者需要把土地、人口和城市变成标准化的形式；看任何 KPI 时问"为了能测量，丢掉了什么"；没有一定的标准化，公共服务就无法提供；子能力 H、D
- 科学林业：只按木材产量优化森林，短期增产，长期出现生态问题；优化一个指标前先列出它没覆盖的功能；边界清楚、目标单一的工程系统可以放心优化；子能力 B、H
- 极端现代主义：相信科学规划能把整个社会设计出来；警惕"从零开始重新设计一切"的提案；局部的、可以撤回的理性设计常常是成功的；子能力 H
- 米提斯：靠经验在具体情境里积累、难以写成规则的本领；向有经验的人请教"手册上没写的事"；这种知识也可能是过时的惯例或偏见；子能力 D、H
- 小步、可逆、预留意外：任何自我改造计划都设计成可以撤回的小实验；有些问题需要统一的大规模行动；子能力 H、B

## 可以直接练的做法
- 情景：学院推出每周进度打分，写出它让什么变得可读、丢掉了什么、会引发哪些规则规避。
- 行动：请一位比你有经验的人讲一件"规章里没写、但做事必须知道"的事，记下来。

## 常见误读
当成反对一切规划。作者批评的是忽视本地知识、又无法纠错的强制性设计。
