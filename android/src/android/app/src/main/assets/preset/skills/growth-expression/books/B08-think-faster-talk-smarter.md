# B08 即兴沟通（Think Faster, Talk Smarter，马特·亚伯拉罕斯，2023）
层级：补充（只取工具）；覆盖子能力：H、B、A；人民邮电出版社 2024，李雪雁译

## 一句话主旨
临场说话的能力可以提前准备：先管住焦虑和完美主义，把场合当成对话，再用少数几个固定结构组织内容。

## 可迁移的模型
- 焦虑管理：承认紧张正常，放慢呼气，把注意力从自己转到听众身上；被点名前用；严重的社交焦虑需要专业帮助；子能力 H
- 敢于平庸：目标是说清楚，不是说精彩，减少边说边给自己打分；被突然提问时用；正式答辩仍然需要充分准备；子能力 H
- 对话而非表演：把提问和闲聊当成交流的机会，而不是考试；进入会场前提醒自己；对方确实在考核你时要兼顾表现；子能力 H、E
- 是什么、所以呢、接下来：先说事实，再说意义，最后说下一步；导师突然问进展时用；复杂论证装不进这个结构；子能力 B、H
- 问题、方案、好处：先说问题，再说方案，最后说对方能得到什么；提议或说服时用；对方不认同问题本身时，要先回到问题上；子能力 B、G
- 先听再答：先复述问题，听出背后的关切，再回答；答问和面试时用；对方只要一个简短事实时这样做显得绕；子能力 A、H

## 可以直接练的做法
- 每天抽一个随机问题，用"是什么、所以呢、接下来"录一段 60 秒的回答。
- 组会被提问时先复述问题再回答，连续做三次。
- 在实验室或食堂和同学闲聊一次，至少追问两次。

## 常见误读
以为即兴靠天赋。书的观点是即兴依赖事先练熟的心态和结构。
