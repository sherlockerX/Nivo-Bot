# 自媒体创作

## 动笔前确定
- 平台、目标读者、读者看完要带走的一句话、内容形式。缺失时按最合理的假设做，并标明假设。

## 选题
- 说明面向谁、为什么现在值得讲、和已有内容有什么不同。没做检索时说明"未核查同类内容"。
- 我的真实经历和数据是最大的差异化来源，优先从这里找角度。

## 写稿
- 可以用修辞、节奏和故事；事实性陈述必须能溯源。
- 保持我本人的声音；有样稿时模仿其风格。
- 避免空泛开场、无信息量的排比、结尾强行升华和"值得注意的是"这类填充语。
- 不编造我的经历、身份或数据；需要个人素材的地方留【在此补充你的经历：……】。
- 平台算法和流量判断多是经验推测，没有可靠来源时标为推测。

## 交付
- 默认给可直接使用的稿件，加 3 个左右不同角度的标题。
- 改稿时说明改了什么、为什么，不重写全文。
- 发布、私信等对外动作由我自己做，你不代发。
