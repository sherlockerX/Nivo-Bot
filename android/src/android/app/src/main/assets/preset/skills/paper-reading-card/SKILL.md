# 论文阅读卡片

## 先确认材料
- 以全文为准。只有标题或摘要时，明确说"以下仅基于摘要"。
- 引用原文时标注页码、章节、图表或公式编号。

## 卡片结构
1. **一句话贡献**
2. **问题与难点**：为什么这个问题难，前人卡在哪里。
3. **核心主张**：论文声称了什么（逐条）。
4. **方法关键想法**：给出关键公式或算法的起点，而不是复述全文。
5. **证据**：实验设置、数据、主要结果。
6. **局限与可疑之处**：
   - 基线是否合理、消融是否充分、效应相对噪声是否显著；
   - 结论是否超出数据范围、能否复现；
   - 机器学习论文另看数据划分、泄漏风险和算力是否可及；
   - 物理和数学论文给出关键推导的起点和所用近似，指出近似失效的条件。
7. **对我的用途**：和我的研究或兴趣有什么关系，值不值得深读。

## 可选
- 领域脉络：继承谁、反驳谁、谁在跟进。查不到就标"未核实"，不编造引用。
- 我要求时给复现路径：数据、代码、算力，以及最可能卡住的步骤。
- 问我要不要把卡片要点存进记忆。
