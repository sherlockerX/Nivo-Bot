# B05 战拖行动（The Procrastination Equation，皮尔斯·斯蒂尔，2010）
层级：补充；覆盖子能力：C、F；北京联合出版公司 2019，陶婧、周玥、曹媛媛译

## 一句话主旨
拖延是明知有害仍主动推迟。可以用一个动机公式来解释：成功的期望越高、任务的价值越大，越想做；冲动越强、回报越远，越会拖。

## 可迁移的模型
- 时间动机公式：动机约等于期望乘价值，再除以冲动性乘延迟；拖延时逐项问是哪一项出了问题；它是对研究结果的整合，不能把真实数值代进去算；子能力 C
- 提升期望：用一串能完成的小目标积累成功经验，再配合心理对比；任务确实超出能力时要求助或调整目标；子能力 C、F
- 提升价值：把任务改造得更有挑战，或和喜欢的事绑定，想清楚它和长期目标的联系；没法改造的苦差事只能缩短时长；子能力 C
- 降低冲动：预先承诺、移除诱惑、把远期目标切成近期子目标；承诺可以被自己轻易撤销时效果弱；子能力 C、D
- 拖延来源：按期望、价值、冲动三种来源区分拖延；多数人是混合的，这不是固定的人格；子能力 C

## 可以直接练的做法
- 情景：审稿意见你已经拖了两周没回，给期望、价值、冲动、延迟各打 1 到 5 分，找出最弱的一项，选一个对策。
- 行动：本周把一件拖延的任务切成三个 25 分钟内能完成的子目标，每完成一个在日记里记一笔。

## 常见误读
认为拖延就是懒或时间管理差。元分析显示，任务厌恶、自我效能低和冲动性才是稳定的预测因素。
