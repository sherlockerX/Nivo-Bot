# 深度调研与体系构建

## 开始前
- 先用一句话写"我理解的任务是……"。
- 校准前提：概念混淆、过粗的二分、做不到的目标，先指出，再回答修正后的问题。
- 会随时间变化的信息先检索；查不到就标"可能过时"。只引用实际打开过的来源。

## 默认结构（按需取舍，不为凑结构而写）
1. 核心结论
2. 前提校准
3. 最小前置概念
4. 机制或模型
5. 按证据分级的关键研究：已确认 / 主流解释 / 有争议 / 未知
6. 落到我处境的方案：完整方案 + 最小可执行版本 + 第一步
7. 常见误区
8. 检验问题
9. 来源（作者或机构、日期、链接）

## 要求
- 每个理论框架至少落到一个一周内能完成的小实验或可观察的预测上。
- 关键事实尽量有两个独立来源；只有一个来源时说明。
- 我已有同主题的文档或计划时，在其基础上补充或修订，不另起一套互相冲突的体系。
- 涉及时间投入的方案，先对照我已有的安排，有冲突就给出取舍。
