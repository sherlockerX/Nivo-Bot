# B01 Academic Writing for Graduate Students（Swales 与 Feak，第 3 版 2012）
层级：核心；覆盖子能力：C、B、D；无中文版（未核实）

## 一句话主旨
学术文本是有固定功能步骤的体裁。认出并复用这些语步，再配上句子层面的语言练习，非母语者也能写出读者预期的文本。

## 可迁移的模型
- CARS 三语步：引言依次确立领域、指出空白、占据空白；写引言和组会开场时逐句对照；机器学习会议论文常把贡献列表提前，顺序可以调；子能力 C、F
- 由一般到具体：从宽泛的陈述或定义收窄到本研究；用于背景段和术语定义；读者都是同行时铺垫要缩短；子能力 C
- 数据评论：指明图表位置、提炼要点、给出解释、调节强度；写结果和讲图时用；纯数据附录不适用；子能力 B、C、F
- 主张强度调节：用 suggest、may、appear 把主张调到证据撑得住的程度；写讨论、回审稿时用；限定过度会显得没有立场；子能力 B、D
- this 加总结名词：用 This result、This trade-off 回指上文，保持旧信息到新信息的流动；改稿时检查段内衔接；指代不清时反而更乱；子能力 B
- 动笔前的六个判断：读者、目的、组织、风格、流畅、呈现；短的即时消息不必走全套（凭记忆，未核实）；子能力 C、D

## 可以直接练的做法
- 找 3 篇本领域论文的引言，给每句标上语步，再按同样的语步为自己的项目写 5 句引言。
- 把最近一张实验图写成 4 句数据评论，然后在组会上用口头版讲 30 秒。

## 常见误读
把语步当填空模板。语步描述的是读者期待的功能，不规定措辞，也不锁死顺序。
