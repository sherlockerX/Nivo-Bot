# B04 福格行为模型（Tiny Habits，BJ·福格，2019）
层级：补充；覆盖子能力：A、B、C、F；天津科学技术出版社（湛庐）2021，徐毅译

## 一句话主旨
动机、能力、提示在同一时刻凑齐，行为才会发生。与其等动机，不如把行为做小、挂在可靠的提示上，再用即时的好感让它扎根。

## 可迁移的模型
- B=MAP：行为没发生时依次检查提示、能力、动机；它是诊断框架，不是能代入数字的公式；子能力 A
- 动机浪潮：动机高时做一次性的结构改变（买设备、删应用），不拿它来承诺每天苦撑；每天重复的行为不能靠动机；子能力 A、B
- 能力链：难度来自时间、金钱、体力、脑力、日常惯例里最弱的一环，找到它对症降低；写综述这类任务拆不到更小时，换成一个"起步步骤"；子能力 C
- ABC 配方：锚点、微小行为、庆祝；锚点写得太模糊（比如"早上"）时失效；子能力 A
- 庆祝：完成后立刻制造一个真实的好感；觉得庆祝很别扭的人效果存疑，这一步也没找到独立的对照试验；子能力 B
- 焦点映射：先为一个愿望列出很多候选行为，挑影响大又容易做的；需要对行为的影响有基本判断；子能力 F

## 可以直接练的做法
- 情景：你想每天发一条自媒体内容却总是拖，用 B=MAP 判断问题出在提示、难度还是动机，写出改进后的 ABC 配方。
- 行动：本周选 3 个微习惯（比如倒完咖啡后打开实验日志），每次完成都做同一个庆祝动作，并在拼图日记打卡。

## 常见误读
以为微习惯会永远停在很小的规模。书中的逻辑是先让行为自动化，再自然扩展。
