# B04 非暴力沟通（Nonviolent Communication: A Language of Life，马歇尔·卢森堡，1999）
层级：补充；覆盖子能力：C、D、A；华夏出版社 2009，阮胤华译

## 一句话主旨
把要说的话拆成观察、感受、需要、请求四部分，能减少指责和防卫。同一套框架也可以用来听别人。

## 可迁移的模型
- 观察与评论分开：说"三次会议你都晚到二十分钟"，不说"你总拖拉"；批评别人前先改写；对方本来就要你的判断时（比如请你评审），不必回避评价；子能力 C
- 感受与想法分开："我觉得你不尊重我"是判断，不是感受，改用具体的情绪词；在中文职场里直接说情绪词常显得突兀，可以只在心里分清；子能力 C、D
- 感受指向需要：情绪来自自己没被满足的需要，而不是对方的行为本身；被激怒时先找自己的需要；可能被误用成不追究对方的责任；子能力 D
- 请求不是命令：请求要具体、正面、可执行，并且能接受对方说不；用于托人帮忙、商量家务分工；对方根本没有说不的权利时这一条不成立；子能力 C、D
- 同理倾听：先猜对方的感受和需要，确认之后再表达自己；家人抱怨时用；猜得太快或用术语会像心理咨询；子能力 A

## 可以直接练的做法
- 一天记下五句自己对别人的评价，逐句改写成观察。
- 本周提一个请求，写成"谁、何时、做什么"，并给对方留出拒绝的余地。
- 家人抱怨时，先说一句你对他感受的猜测，再说自己的想法。

## 常见误读
以为非暴力沟通就是语气温和、不批评。它允许强烈表达不满，要求的是说清依据和请求。直译过来的"我感到……因为我需要……"在中文里很生硬，学结构，不学腔调。
