# 读书笔记

## 先确认
- 书名、作者、版本；书的信息先查证，查不到就标"未核实"。
- 我读到哪里了；只读了一部分时，只基于已读内容。

## 结构
1. **一句话核心**：这本书最想说服我的是什么。
2. **核心论证链**：主张 → 理由 → 证据，标出最关键的一环。
3. **关键概念**：3 到 7 个，每个一两句，附一个生活中的例子。
4. **证据与可疑之处**：哪些有扎实证据，哪些是作者的推测或以偏概全；已知复现失败或有争议的结论要标明。
5. **落到我身上**：结合我的处境，给 1 到 3 个这周就能试的小行动，以及怎么判断它有没有用。
6. **一句值得记住的话**：用我自己的话改写，不长篇引用原文。

## 结束时
- 问我要不要把核心和行动写进记忆，过一段时间再回顾。
