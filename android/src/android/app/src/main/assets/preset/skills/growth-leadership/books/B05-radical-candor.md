# B05 绝对坦率（Radical Candor，金·斯科特，2017）
层级：补充；覆盖子能力：C、E、G；中信出版集团 2019

## 一句话主旨
好上司同时做到关心个人和直接挑战。衡量反馈的标准是对方听到了什么，而不是你说了什么。

## 可迁移的模型
- 二乘二：关心个人和直接挑战两条轴，分出绝对坦率、恶意攻击、过度同情、虚伪操控四格；每次反馈后自评落在哪一格；权力差距大或跨文化时，"直接"的分寸要调；子能力 C、E
- 先要批评：先请别人批评自己，并用行动奖励说真话的人；问"我做什么或停止做什么，会让和我合作更容易"，然后沉默等着；对方从没被允许批评上级时，头几次只会得到客套；子能力 C、E
- 反馈的形式：及时、当面、具体、对事不对人，批评私下说，表扬可以公开；公开表扬会让有些内向的人不舒服，先问对方的偏好；子能力 C
- 看落地效果：根据对方的反应调整，而不是认定"我已经说过了"；反馈完问一句"你怎么看"；对方情绪很强时先停，改天再谈；子能力 C、B
- 成长轨迹：分清快速上升的人和稳定发挥的人，给不同的机会和期待；标签容易固化，人会在两种阶段之间转换；子能力 G
- 把事做成的循环：倾听、澄清、辩论、决定、说服、执行、学习；小事也套流程会变成负担；子能力 E、H

## 可以直接练的做法
- 向一位同学要一次批评，只听不辩解，记下内容。
- 情景：师弟的代码第三次没写测试，给一次两分钟的坦率反馈。
- 情景：同伴在组会上提了一个有漏洞的想法，怎么挑战又不伤人。

## 常见误读
把"坦率"当成刻薄的许可证。作者明确说，没有关心的直接挑战就是恶意攻击。
