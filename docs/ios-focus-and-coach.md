# Focus and Coach on iPhone

From Focus, choose Link task to search open tasks or add one to an existing group. Saving the task selects it; the timer starts only when you tap Start. After a pomodoro you can start a break. Every fourth completed pomodoro of the local day offers a longer break. After the break you can return to the previous task. Focus statistics can divide measured time by group or tag. Time shared among tags is counted once in the total.

In the full-screen timer, the lock button shows the iPhone's Guided Access status and how to start and end it. A scheduled reminder opens Focus for you to start the timer. Neither feature automatically locks other apps. The Android lock scheduler and app whitelist are not implemented on iOS.

Open a skill in Coach to review today's lesson, previous attempts, relevant material and the next step. During a normal chat you can ask for saved reflections or focus time in a date range. A reflection's save time is not evidence of time spent; records without a measured duration are identified separately.

The [iOS build workflow](https://github.com/sherlockerX/Nivo-Bot/actions/workflows/ios-check.yml) runs core tests on macOS, builds the device app and compiles the application tests. A successful build provides an unsigned IPA for signing. Notifications, Guided Access, live model replies and transitions between screens still need an iPhone check.
