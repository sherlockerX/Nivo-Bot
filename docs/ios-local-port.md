# Nicholasx iPhone 版移植

本页记录把 Android 本地构建的页面移植到 iPhone 的进度和两边的差异。页面结构、入口、卡片布局、文案和颜色与 Android 一致，控件用 iOS 原生的。iPhone 版只在 GitHub 的 macOS 构建机上做编译检查，还没有在真机上运行过。

## 预置内容

首次启动时装入与 Android 相同的预置内容：六门能力课程和建课框架 `growth-course-builder`（每门课带 `books/` 下的拆书卡）、USER.md、GLOBAL.md 和教练引导语。每样只装一次，文件只在为空时写入；删掉的预置技能不会再装回来，没改过的预置技能跟随新版本升级。打包文件 `android/src/ios/NanoMuse/Resources/preset.json` 由 `scripts/ios-preset.py` 从 Android 的 `assets/preset/` 生成，`--check` 检查它是否最新。

## 教练页

底部第二个标签从“动态”改为“教练”，内容与 Android 相同：

- 顶部是正在培养的能力（等级、升级进度、目标等级、今日已答和连续天数），下面是今日回忆。
- 页面只放今天的训练卡，标题写成“今天 · 星期一 · 2026年11月2日”，不分上午下午。每张卡有问题和回答框，提交后在教练自己的会话里点评，卡片下显示 0 到 4 分、点评和“太简单、合适、太难”。
- 右上角左边是训练日历：按月显示，有卡的日子下面有一个点，点某一天列出那天的卡，没答的卡在日历里也能作答。卡保留 90 天。右边是训练设置：每项能力由哪个技能训练（点开进入技能详情）、出题用到的知识、引导语、每天写卡的开关和时间、“现在写一版”。
- 点能力卡打开“能力与成长”：调整顺序、设为当前、暂停、建课、添加能力、设定换下一个能力的等级，查看我的框架、成长记忆和我的原则。
- “现在写一版”没有写出卡时，页面上说明原因：没有在练的能力、没有模型、教练还在点评、模型请求失败或回复里没有训练卡。

与 Android 的差异：

- iPhone 上没有拼图日记，训练设置的“出题用到的知识”里没有拼图日记和习惯两行，写卡时也不调用 `minis-jigsaw-cli`。
- 每天的定时写卡只在 App 打开时运行，到了设定时间手机会提醒打开 App。
- 新增文案有英文和简体中文，其他语言显示英文；Android 这部分文案同样只有中英文。
