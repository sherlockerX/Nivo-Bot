# Nivo Bot 2.0.0

Nivo Bot brings the Android work into a named product: AI chat, reusable task groups and tags, focus timing, daily fragments and growth coaching share one local workspace. The product website is https://nivo.8666886.xyz/.

## Highlights

- Android display name: Nivo Bot. Version name: 2.0.0. Version code: 51.
- Retained task revision checks, category management and actual focus-time accounting from the local Android work.
- Added a recoverable full-screen focus view with local background selection.
- Added the product website, download metadata and source-release tooling.

## Upgrade notes

The application ID remains `io.github.nanomuse.app`. This release uses the dedicated signing certificate introduced in local build 50, SHA256 `9513428b8daaf23fe211b8b63d7830737d0468aaea360b49acaf88bb6de1d6a3`. It cannot normally replace an installation signed with the old Android Debug or upstream key. Do not uninstall an existing installation before checking backup and restore coverage for chats, coaching, tasks, focus records, fragments and attachments. Cross-certificate restoration has not been verified.

Android, website and source changes are included. Uncommitted iOS work is not included in this release. Other platforms retain their existing versions. Cached native inputs were used for the local build; a clean-machine native build and real-provider verification remain separate checks. Do not treat the upstream free service descriptions as Nivo Bot service commitments.

## Source and community

Source: https://github.com/sherlockerX/Nicholasx. The repository name is retained. Report issues without API keys, private conversations or signing material.
