# Nivo 2.0.10 · Glimmer

Android and iOS use the name Nivo and share version `2.0.10` (build `61`). The default companion is Shiqi (十七). A personal assistant name or edited memory stays unchanged in its existing data container.

## Highlights

- Android chat shows three pulsing stars while waiting for the model and during active reasoning. Tools show their own status. The stars disappear when the answer begins and remain still if system animations are disabled.
- On iOS the app, sharing, Files and activity extensions use the Nivo display name. Existing bundle identifiers and app groups are unchanged.

## Installation

- **Android:** arm64-v8a, Android 8.0 or later. The new application ID is `io.github.nivo`. Keep the previous application: neither `io.github.sherlockerx.nelan` nor `io.github.nanomuse.app` can be updated in place by this APK. Use the [migration guide](https://nivo.8666886.xyz/install.html#android-migration) for supported transfers. Focus history, daily fragments and Coach progress are not covered by the general backup. A Debug installation under the new ID also cannot be updated in place with a different signing certificate.
- **iOS:** arm64, iOS 16 or later. The Release IPA is provided unsigned for self-signing. It is not an App Store or TestFlight installation. Keeping the application identity when re-signing matters for existing iPhone data.
- The [download catalogue](https://nivo.8666886.xyz/downloads.html) lists both platforms, the matching source and checksums. Previous files retain the names and hashes under which they were published.
