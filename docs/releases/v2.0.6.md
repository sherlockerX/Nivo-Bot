# Nivo Bot 2.0.6 · Harbor

**Nivo Bot`2.0.6`“Harbor”** updates the iOS app's local startup, model setup and daily-use screens.

The iOS app opens local features without the former project account. Model configuration can be skipped and completed when needed. Tasks, focus, fragments and Coach open their editors with the current local data scope, while settings transitions wait for the preceding sheet to close.

## Highlights

- **Local startup and recovery.** The app keeps a persistent local storage fallback when personal signing removes App Group access. Legacy data migration preserves conflicting originals and remains retryable. Provider credentials move to device-only Keychain storage with checked recovery.
- **Optional model setup.** The welcome screen lets you skip setup. Chat offers a configuration entry without discarding an unsent draft. Custom API endpoints, provider authentication and user-configured MCP remain available.
- **Retired project services removed.** The personal iOS build no longer starts the original account, project relay, cross-device sync, CloudKit or iCloud backup flows. Obsolete repository/update requests and preset relay-provider recommendations were removed. Manual backups remain available.
- **Daily pages open reliably.** New fragments, starting focus, reminders, task details, groups, tags and the Coach calendar carry their data scope in the presentation request. Settings, routines and avatar controls open after the first sheet is dismissed.
- **A clearer daily layout.** Daily fragments show the date, the day's shape and Camera, Album and Reflection actions. Tasks, Focus and Coach use a compact title bar; the main chat no longer carries the daily ideas strip.
- **Photo imports preserve the active draft.** The fragment editor blocks saving while an image is being read, offers cancellation, and rejects results from canceled or closed imports. Camera opens after the current draft is saved, so canceling capture preserves the preceding text.

## Upgrade Notes

- This build targets **iOS16 or later**, version **2.0.6**, build **57**. The delivery is an unsigned arm64 IPA requiring your own signing setup. It is not a TestFlight or App Store release.
- Preserve a manual backup before changing an installation or signing identity. Personal signing can remove shared-container access; sharing extensions and the file provider still depend on actual entitlements. An unsigned build does not prove the installation or upgrade path on an iPhone.
- Existing API services are selected and configured by the user. Requests to those services can send prompts, tool results or attached content according to the selected feature. Local mode does not make external model requests offline.
- The repository's common version files move together, but this delivery builds **iOS only**. Android's available package remains the version identified in the download catalogue. Updating source version fields is not evidence of a new Android binary.

### iPhone acceptance

1. Sign the IPA with the identity used for the installed app, install it and check that About shows 2.0.6. Confirm that existing conversations and personal records are present. An installation using a different identity is a separate migration test.
2. On an installation without a configured model, use Skip for now and open Tasks, Focus and Fragments. Return to Chat, enter a draft and open model setup; confirm that returning preserves the draft.
3. Enter a reflection, immediately open Camera and cancel. Close and reopen the draft and check its text. Then select a slow-loading library photo, cancel the import and select a different one; only the latest successful choice should appear.
4. Open a new fragment, Start focus, a focus reminder, task details, groups, tags and the Coach calendar. Open settings, routines and Avatar studio in succession and check that each screen opens and returns normally.
5. Start focus from a task, finish it and save a linked reflection. With your own model configured, ask Chat to read the saved record and confirm that it distinguishes the measured session from a written note.
