# Nivo Bot 2.0.5 · Cadence

**Nivo Bot `2.0.5` “Cadence”** connects tasks, measured focus time, reflections and skill practice on Android and iOS.

Start a focus session from a task, take a break when it finishes and save a reflection linked to the actual session. Coach brings each skill's goal, current evidence, today's lesson and past practice together. Ordinary chats can review saved personal records while keeping a written note distinct from measured focus time.

Android adds forced focus and recurring lock plans. iOS uses native screens for tasks, focus, fragments and Coach, with reminders and instructions for the system's Guided Access. The iOS package is an unsigned IPA for personal signing.

## Highlights

- **Tasks and focus stay connected.** Search open tasks or create one from Focus, start a timer from a task and review time by group or tag. Pomodoros lead into short breaks, with a longer break after every fourth completed pomodoro of the local day. Finishing a timer does not automatically complete its task.
- **Reflections retain their context.** Completed focus sessions open recoverable reflection drafts with measured intervals and task links. A task-status change remains an explicit choice. Saved notes without a linked measured interval are identified separately when AI reads personal records.
- **Coach follows one skill over time.** Skill profiles show goals, current performance with supporting answers, today's training, material and lesson history. A skill keeps its training conversation across units and days. Lesson preparation uses a separate model call without tools, validates the returned plan and falls back to the course exercise when needed.
- **Android forced focus has its own controls.** Countdown and stopwatch sessions, recurring time periods, allowed apps, recovery alarms and a delayed emergency exit support focused sessions. Cross-midnight plans end at their actual deadline; failed settlement no longer keeps the lock screen past the end. These controls require the permissions and setup described in the [forced-focus guide](../focus-lock.md).
- **iOS keeps its platform boundary visible.** Focus reminders open the Focus page for the user to start a timer. Guided Access instructions explain how to start and end the system feature manually. Android's forced lock plans and app whitelist are not implemented on iOS, and a timer ending does not end Guided Access.
- **Saved work and provider changes recover more carefully.** iOS adds account-scoped tasks, focus, fragments and Coach, checked backup and configuration writes, recoverable provider and credential changes, and guarded chat synchronization. Android retries transient model failures before moving to a fallback model, and record queries use the phone's time zone.
- **iOS build artifacts remain separate from tests.** The workflow packages the unsigned device app before application-test compilation embeds XCTest. It also corrects the copy-test resource loader and makes OAuth tests import the actual application module.

## Upgrade Notes

- **Version:** Android `versionName` and iOS `MARKETING_VERSION` are `2.0.5`; Android `versionCode` and iOS build number are `56`.
- **Android:** Android 8.0 or later, arm64. The application ID remains `io.github.nanomuse.app`. An update requires the same signing certificate as the installed application. Old Debug or upstream signatures normally cannot be replaced by the dedicated Nivo release signature. Check backup and restore coverage before uninstalling; cross-certificate restoration has not been accepted.
- **iOS:** iOS 16 or later. This fork currently has no Apple Developer Program account, so it provides no TestFlight or App Store distribution. Download the unsigned IPA from the product website, then sign it with your own valid signing setup before installation. The raw IPA cannot be installed directly. Signing credentials and provisioning profiles are not included.
- **Data:** Preserve a backup before migrating devices or replacing an installation. Tasks, focus, fragments, Coach and attachments have module-specific backup rules. Recurring lock plans restored on Android remain disabled until configured again.
- **Scope:** This release covers Android, the unsigned iOS delivery and the product website. Retained desktop, runtime, relay and web-console source has a separate release scope. Model service costs and account requirements belong to the provider you configure.

## Community

Nivo Bot is free, open source and non-profit. The official repository is [sherlockerX/Nivo-Bot](https://github.com/sherlockerX/Nivo-Bot). Report reproducible problems in [Issues](https://github.com/sherlockerX/Nivo-Bot/issues) with the platform, version and steps, keeping keys, private conversations and signing material out of reports.

Nivo Bot builds on [nanoMuse](https://github.com/nano-muse/nanoMuse) and [OpenMinis](https://github.com/OpenMinis/OpenMinis). GPL-3.0-or-later, upstream copyright notices and DCO contribution requirements remain in force. A source checkout needs `git submodule update --init --recursive` for its pinned native dependency sources. Upstream hosted-service descriptions do not establish Nivo Bot service commitments.

从待办进入专注，计时结束后休息，再保存关联本次实测时间的反思。教练按技能展示目标、当前证据、今日训练和历史练习。普通聊天可以查询已保存的个人记录，并区分文字记录与实际测得的专注时间。

### 亮点

- **待办与专注相互连接。**在专注页搜索未完成任务或创建任务，也可从待办直接开始计时。统计支持按分组或标签查看时长；番茄钟结束后可开始短休息，每个本地日期完成第4次番茄钟后提供较长休息。计时结束不会自动完成任务。
