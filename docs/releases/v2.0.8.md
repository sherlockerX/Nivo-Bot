# Nivo Bot 2.0.8 · Clarity

**Nivo Bot `2.0.8` “Clarity”** improves iOS tool queries, configuration output and recovery messages for personal records.

Configuration queries recognize full model IDs, failed session actions report failure consistently, and record-query errors explain which condition needs attention. Map commands reject invalid arguments and return resolved endpoints and service errors for diagnosis.

The user reported no issues after checking the audit branch on an iPhone. That feedback applies to the check build, which retained version `2.0.7 (58)` and used Debug. The new `2.0.8 (59)` unsigned Release build passed complete release CI and local artifact verification. Its actual IPA still requires iPhone acceptance after personal signing. Artifact identities are recorded below; CI and local checks do not verify public download availability.

## Highlights

- **File sorting has a name.** Choose **Sort By** to switch between **Default** and **Last Modified**. An empty editable file offers **Edit**. A failed save keeps the draft open, and unreadable preferences offer **Retry**. The scheduled-task summary is read-only.
- **More of the interface follows your language.** Two passes filled 100 Simplified Chinese strings across model setup, authorization, backup and restore, speech, browser downloads, Shortcuts and Live Activities. The Dynamic Island uses the same localized running count as the Lock Screen.
- **Configuration paths and output preserve their meaning.** Model IDs containing dots are matched as complete IDs. Quiet reads retain JSON scalar, array, object and null values. Missing leading arguments fail before account access, and output flags no longer swallow model-use commands or search terms.
- **Runtime model access has a clearer explanation.** The tool list describes the separate model authorization setting. `--all` still lists only authorized, enabled models and respects explicit filters. This does not change the existing advanced raw-request passthrough contract into a provider-side model whitelist.
- **Personal records explain why a query failed.** Errors distinguish foreground, conversation, saved-request and storage conditions. Framework tool titles are accepted as display metadata. Life-log dates follow the device time zone, compact JSON is supported, and Markdown pagination exposes its next offset.
- **Session and scheduled-task commands report failures consistently.** Session status no longer nests duplicate response envelopes. Failed actions return a failed outer response and exit code. Missing task IDs and write revisions are rejected before account or permission access.
- **Map commands expose useful evidence.** Cycling remains cycling, ambiguous place matches require disambiguation, and results identify resolved endpoints. Timeouts cancel their requests and reject late results. Coordinate, distance and region bounds are validated, including polar and global search regions. These changes do not establish the accuracy or availability of live Apple map services.
- **Release artifacts record their origin.** Manual CI can build Debug or Release and records the actual commit, run URL, app identity, architectures, unsigned status, file size and SHA256 beside the IPA. Missing translations for 13 existing interface strings were completed across seven supported locales.

## Upgrade Notes

- **iOS package:** the verified artifact is `2.0.8 (59)`, built with the Release configuration for iOS16 or later. It remains unsigned and requires personal signing before installation. Release optimization does not provide an Apple signature, TestFlight distribution or App Store approval; this fork has no Apple Developer Program account.
- **Existing iPhone data:** retain the signing identity and app container used by the installed copy when signing an update. Changing signing or installation identity can affect access to existing data. Back up important records before replacing the app, and do not uninstall solely to resolve a signing mismatch.
- **Android stays at `2.0.7 (58)`:** its APK, source archive, checksum file, application ID and signing certificate are retained. This release does not rebuild or rename those Android artifacts. The [Android release notes](v2.0.7.md) remain the record of their verification and limitations.
- **Platform scope:** this release builds a new iOS binary only. Forced focus, recurring lock plans and app whitelists remain Android features. iOS provides reminders and Guided Access instructions that the user starts and ends in iOS. No new desktop or server package is established by these notes.
- **Corresponding source:** use the source bundle for the installed platform and version. The iOS source archive identifies build commit `4163621fba0d40cabdb7354eaba8f9b97ad7be5c` and dependency coverage in its manifest. External dependencies and Apple toolchains remain necessary; the optional Linux kernel is pinned but unexpanded because the committed iSH configuration excludes it. A source archive is not a claim of byte-for-byte reproducible binaries.

The source review covered all eight main destinations, sidebar and classic settings, file browsers, and system extensions. It scanned 742 production source and storyboard files, including 223 with view declarations, controls, navigation or extension entry points. These are file counts, not a count of screens exercised on a phone. After signing, use **System files → Sort By** to check the selected order, open an empty editable file, then check that `HEARTBEAT.md` offers no edit action. With Simplified Chinese selected, check the backup passphrase fields, restore confirmation without confirming a restore, and the browser’s empty downloads view. Test large text and VoiceOver on the phone.

The earlier application test target was compiled with `build-for-testing`; its tests were not executed. Native map regressions used offline substitutes and did not call Apple map services. Live provider requests, route accuracy and every phone interaction cannot be inferred from compilation or the user's general feedback. The [tool audit](../zh/ios-tool-self-audit.md) records the earlier evidence and remaining boundaries, including the existing limit on outer-shell cancellation.
