# Nivo 2.0.11 · Serene

Android and iOS share version `2.0.11` (build `62`). Thinking and execution summaries now sit inside pale-blue capsules, with matching rounded containers for expanded details.

## Highlights

- Wrapped waiting indicators and process summaries in a pale-blue background with clearer blue-gray text and a fine border.
- Used large rounded corners for long thinking and execution details. Existing folding, scrolling, first/latest-step navigation and tool details remain available.
- Added matching dark-blue surfaces for dark mode. Android summaries keep a minimum 48dp touch target; iOS accessibility text sizes use larger corner clearances.

## Upgrade notes

- **Android:** arm64-v8a, Android 8.0 or later. This release keeps `io.github.nivo` and the existing release certificate, matching the 2.0.10 installation identity. Install over the signed 2.0.10 app to keep its data; do not uninstall it first. Installations with a different certificate cannot be updated in place. Versions using `io.github.sherlockerx.nelan` or `io.github.nanomuse.app` remain separate apps. See the [migration guide](https://nivo.8666886.xyz/install.html#android-migration) for supported transfers.
- **iOS:** arm64, iOS 16 or later. The Release IPA requires self-signing. Existing bundle identifiers and app groups are retained. The identity and entitlements selected by the signing tool determine whether existing device data remains accessible. This is not a TestFlight or App Store distribution.
- The [download catalogue](https://nivo.8666886.xyz/downloads.html) provides platform files, corresponding source and checksums. Previous downloads retain their original files and hashes.

## Verification

Before version preparation, Android regression tests passed 1,849 cases with two skipped and no failures. One thinking-stars instrumentation test passed. An isolated Android36.1 emulator verified light and dark themes, 1.5x text size, process details, first/latest-step navigation, tool details and return to chat. These checks used synthetic offline records and do not replace physical-phone installation or model-service testing.

Final Release package and GitHub build evidence will be attached after their checks complete. The existing Android 16KB page-size limitation for rclone remains.
