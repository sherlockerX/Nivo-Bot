# Nivo 2.0.12 · Threadline

Android and iOS share version `2.0.12` (build `63`). This release brings the latest committed chat changes into both mobile apps: compact process summaries, a status timeline and folding for long thinking.

## Highlights

- Aligned the thinking and execution summary with the answer. Its outlined background follows the content width and shows the current step while work continues.
- Presented the opened steps as a timeline, with separate indicators for thinking, running tools, completed tools, failures and cancellations.
- Collapsed finished thinking to a three-line preview in the steps panel. Tap to expand it; active thinking stays open until it finishes unless you choose otherwise. Android supports Show all and Show less; iOS retains its existing windowed display for very long thinking.
- Kept tool details, Stop, long-press actions and first/latest-step navigation available.

## Upgrade notes

- **Android:** arm64-v8a, Android 8.0 or later. The application keeps `io.github.nivo` and the existing release certificate. Install over the signed 2.0.10 or 2.0.11 app without uninstalling it first. Earlier package IDs remain separate installations; see the [migration guide](https://nivo.8666886.xyz/install.html#android-migration).
- **iOS:** arm64, iOS 16 or later. The Release IPA requires self-signing. Existing bundle identifiers and app groups are retained. The signing identity and entitlements chosen during installation determine access to existing data. This fork does not provide TestFlight or App Store distribution.
- Previous release files keep their original names and checksums. The [download catalogue](https://nivo.8666886.xyz/downloads.html) lists the available packages and corresponding source.
