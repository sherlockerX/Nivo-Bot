# 念步品牌

## 手机产品名称

Android和iOS源码在简体、繁体中文下显示为**念步**，其他语言下显示为**Nelan**。内置伙伴为**十七／Shiqi**。产品名和助手昵称分别维护；个人昵称文件存在于当前应用数据容器时继续沿用。

本次适配覆盖桌面、设置、权限说明、通知、分享和文件入口。iOS的分享扩展、文件提供器和动态小组件分别打包自己的本地化InfoPlist.strings。发给模型的产品说明使用当前名称，命令和协议标识沿用原值。

默认助手模板按完整内容识别。Android和iOS只把未经修改的历史默认模板迁移为十七。预置长期记忆也采用同样的规则：完整的旧默认内容可以更新，个人事实、自定义昵称和修改过的正文继续保留。新默认记忆以SOUL.md为助手身份来源，并引导助手使用现有记录工具，不再声称无法读取生活记录。现有云同步入口仍保持关闭。

显示规则如下：

- 普通页面、提示、通知和AI默认自我介绍使用念步／Nelan、十七／Shiqi。本地保存说明不再介绍已经移除的账号或跨设备同步服务。
- 高级工具优先说明用途，例如管理应用设置。详情和终端保留实际命令、路径和格式，包括`minis-config`、`/var/minis`和`.minisbak`。命令或路径中的历史标识不代表另一个产品名。
- 关于页明确将**nanoMuse**和**OpenMinis**列为上游项目，保留许可证和版权署名。旧对话、导入文档及用户自行编辑的身份或记忆文件不会为了清理历史名称而被改写。

品牌生成与版本生成分开执行：

```sh
python scripts/rebrand.py --android-brand-only
python scripts/rebrand.py --ios-brand-only
```

这两个入口保留版本字段、安装标识、签名配置、App Group、Keychain访问、数据库与文件路径、URL scheme和现有官网地址。代码命名空间及素材文件名保留nanomuse以维持兼容。上游致谢、许可证及停用历史服务的说明继续保留原名；这不表示手机本地产品新增了云服务。

本轮另行确认Android`2.0.9(60)`使用新应用ID：**`io.github.sherlockerx.nelan`**。它与旧包**`io.github.nanomuse.app`**并存，拥有独立私有目录和权限。即使沿用原签名证书，也不能覆盖更新旧应用或自动读取旧应用的数据。相对路径和`com.openminis.app`源码命名空间用于兼容，不代表两个安装共享存储。

迁移须在旧应用导出，再在新应用中导入各自支持的类别。通用`.minisbak`不包含心得记录与照片、教练进度、专注历史或自定义宠物设置。待办有独立JSON导出与导入；专注可导出历史，但导入端只恢复停用状态的锁定计划和白名单。完整范围见[发行说明](../releases/v2.0.9.md#moving-from-the-old-android-package)。在确认可迁移内容和留存记录之前，应保留旧应用及其数据。

最终`Nelan-v2.0.9-arm64.apk`、源码归档及校验文件已完成本地核验，替代过时的旧包名候选；APK的新身份及原正式证书均已确认。源码包固定于APK源码提交`905f9f23cba0017083a3fc50f3d443a7ade55f9b`，最终核验文档由后续发布提交记录。公网部署与下载核验仍待完成。iOS源码包含对应品牌与伙伴变更，但本轮没有Xcode构建或iPhone验证，也不发布新IPA。iOS下载保留`2.0.8(59)`，该旧包不包含本轮源码变更。

## 标志 {#the-mark}

一笔连续的笔画，读出来是一个 **N**：带钩的起笔、一个圆峰、一条长斜线、一个收紧的谷、向上的收笔；
一个只有一个拱的 N，一笔画成，不抬笔。标志刻意做得抽象：它先是一个手势，然后才是一个字母。

- 源文件只有一个：`assets/brand/nanomuse-icon-source-1024.png`（最终渲染，品牌蓝底上的白色圆角方块）。
  其余一切都由它派生。
- `assets/brand/nanomuse-mark.svg`：只有笔画本身，描成一条填充路径，viewBox
  `0 0 100 100`，用方块坐标，渐变填充。
- `assets/brand/nanomuse-icon.svg`：白色圆角方块（`rx=27`）加标志。这就是应用图标。
- `assets/brand/nanomuse-icon-on-blue.svg`：放在品牌蓝背景上的图标，只用于商店页面和启动页。
  凡是用图标代表这个应用的地方（README、网站、社交卡片、favicon）都用素净的那块：白底、标志、
  一道细边，没有背景。
- `assets/brand/nanomuse-mark-rgba-688.png`：带透明通道的笔画，688 px，位图兜底。
- `docs/app-icon.png`：带圆角渲染出来的方块（27 % 圆角半径，外侧透明，一道 `#D9D9DE` 细边，
  放在白底上也保得住形状），512 px：图标在主屏幕上的样子。它是 README 的头图，也是任何把念步
  当作一个 App 展示的地方该用的那张图。

图标**不是**伙伴形象。手机端内置伙伴为**十七**，动画状态见[形象](avatar.md)。已有自选形象和视频继续保留，资源名dragon用于历史兼容。不要把伙伴形象放到启动器图标上，也不要用N标志代替助手的脸。

## Android 映射（S1 已完成） {#android-mapping-done-in-s1}

- 自适应图标：背景层 = 纯色 `#FFFFFF`；前景层 = 标志，一个 `VectorDrawable`，`fillColor` 是上面那个
  两档线性渐变；单色层 = 同一条路径，平涂填充（由 Android 着色）。
- 图标皮肤（从 OpenMinis 保留下来的 activity 别名）：*自动* = 白色方块；*浅色* = 白色方块；
  *深色* = `#0F1B33` 方块加白色标志。
- 通知小图标：标志，平涂白色，24 dp。
- 永远不要发布旧的 OpenMinis 图标、名字，或者字母 n 的那些草稿。

## 不要这样做 {#don-ts}

- 不要把标志涂成蓝色渐变、平涂白、平涂黑以外的颜色。
- 不要旋转、描边，也不要给笔画加阴影。
- 不要把标志直接放在品牌蓝上而不垫白色方块（对比度不够）。
- 不要把别的产品的标志、名字或蓝色当作素材；标志只有我们自己这一个。
