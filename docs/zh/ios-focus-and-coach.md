# 在iPhone上使用专注和教练

在专注页点「关联待办」，可以搜索未完成的待办，或在已有分组中新建一条。保存后会选中该任务，点「开始」才计时。番茄结束后可以接一段休息，当地当天每完成第4个番茄会提供较长休息。休息结束可回到先前的任务。统计可按分组或标签查看实际投入；同一时段有多个标签时分摊时长，总时长不会重复累加。

全屏计时中的锁形按钮显示iPhone的引导式访问状态和系统开启、退出方法。预约专注提醒后，点击通知进入专注页，再自行开始计时。引导式访问和专注提醒都不会自动锁定其他应用。Android的自动锁机计划和应用白名单尚未移植到iOS。

在教练页打开一项能力，可以回看今天的训练、之前的回答、材料和下一步。在普通聊天里也可以询问某段日期的心得与专注时长。心得的保存时刻不能当作投入时长；没有实测时长的记录会单独说明。

[iOS构建工作流](https://github.com/sherlockerX/Nivo-Bot/actions/workflows/ios-check.yml)在macOS上运行核心测试、编译设备应用和应用测试。构建成功后可下载未签名IPA，签名后才能安装。通知、引导式访问、真实模型回复和页面切换仍需在iPhone上验证。
