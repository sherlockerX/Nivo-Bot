Nivo Bot은 일상을 위한 AI 작업 공간입니다. 대화에서 시작해 다음 단계를 할 일로 만들고, 집중할 시간을 정한 뒤 돌아볼 수 있는 기록으로 경험을 남깁니다.

무료 오픈 소스 비영리 프로젝트입니다. 모델 제공업체를 직접 선택하며 요청 비용은 제공업체에 따릅니다. Android 시스템 TTS로 답변을 읽습니다.

## 주요 기능

| 영역 | Android 기능 |
|---|---|
| AI 채팅 | 모델 제공업체 설정, 통합 할 일 및 집중 도구, Android 시스템 TTS를 통한 답변 읽기. |
| 아이디어 | 날짜에 따라 갱신되는 업무, 생활, 학습, 가족과 관계, 콘텐츠 제작 등 여러 분야의 제안. |
| 할 일 | 저장된 그룹과 태그 재사용, 달력·사분면·그룹·상태 보기 전환, 완료한 할 일의 태그 비율 확인. |
| 집중 | 할 일에 연결한 카운트다운이나 스톱워치, 일시 정지와 재개, 로컬 배경을 사용하는 복원 가능한 전체 화면 타이머. |
| 일상 기록 | 매일의 경험을 기록하고 할 일 진행 상황이나 종료된 집중 세션을 연결. |
| 코치 | 역량 영역 탐색, AI 채팅을 통한 강좌 제안, 일일 연습 대화와 학습 기록 검토. |

할 일 차트는 태그별 완료 건수를 집계하며 투입 시간을 나타내지 않습니다. 집중 통계는 실제 시간을 기록하고, 세션 종료가 할 일의 자동 완료로 이어지지 않습니다. 강좌를 보는 것만으로 습득 처리하지 않습니다.

## 하나의 생각, 연결된 하루

예를 들어 매일 조금씩 책을 읽고 싶다면:

1. <strong>먼저 이야기하기.</strong>AI와 목표를 구체화하고 앱 도구로 읽기 할 일을 만듭니다.
2. <strong>자리 마련하기.</strong>저장한 그룹과 태그를 재사용하고 편한 보기에서 할 일을 찾습니다.
3. <strong>시간 내기.</strong>할 일에 연결한 집중을 시작하고 배경을 골라 전체 화면 타이머를 엽니다.
4. <strong>경험 남기기.</strong>종료된 세션과 진행 상황을 일상 기록에 연결하고 발견을 적습니다.
5. <strong>계속 배우기.</strong>채팅에서 강좌를 제안하고 일일 연습을 거쳐 코치 기록을 돌아봅니다.

연결이 특징입니다. 같은 생각이 대화, 행동, 시간과 회고로 이어집니다.

AI는 앱 도구를 통해 할 일 변경을 저장합니다. 대화 답변만으로는 할 일이 저장되지 않으며, AI가 완료 처리하려면 현재 사용자의 명시적인 완료 보고가 필요합니다. 집중 시간은 타이머가 측정하며 모델이 만들어내지 않습니다.

학습, 할 일, 집중과 일상 기록은 로컬 저장소를 사용하며 모듈마다 계정과 백업 규칙이 다릅니다. 모델에 보내는 메시지는 설정한 제공업체가 처리합니다. 기기 이전 전에 권한과 백업 범위를 확인하세요.

## 소스에서 빌드

<details>
<summary>개발 상세</summary>

네이티브 의존성 하위 모듈도 함께 복제합니다:

```bash
git clone --recurse-submodules https://github.com/sherlockerX/Nicholasx.git
cd Nicholasx
```

JDK 21, Android SDK 36, NDK 27.2.12479018, CMake 3.22.1을 사용합니다. Gradle Wrapper 8.11.1이 포함되어 있습니다. 도구를 설정한 다음 Linux 또는 WSL에서 네이티브 의존성을 준비하세요:

```bash
bash scripts/android/build-natives.sh
```

Windows PowerShell 7:

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk21'
$env:ANDROID_HOME = 'C:\path\to\android-sdk'
./scripts/android/Build-Android.ps1 -Target Check
./scripts/android/Build-Android.ps1 -Target Debug
```

네이티브 입력, 테스트, 결과물과 릴리스 서명은 [Android 개발 안내](../android-development.md)를 참고하세요. 서명 키와 인증 정보는 저장소 밖에 보관합니다. 캐시를 사용한 빌드 성공은 새 환경의 빌드나 실제 기기 호환성을 검증하지 않습니다.

</details>
