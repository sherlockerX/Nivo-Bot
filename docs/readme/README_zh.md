Nivo Bot是一个面向日常生活的AI工作台。从一句想法开始，把下一步变成待办，留一段时间专注，再把经历保存在可以回顾的记录里。

免费、开源、非营利。模型服务由你选择，调用费用以服务商为准；回复朗读使用手机已有的Android系统TTS引擎。

## 可以做什么

|模块|Android功能|
|---|---|
|AI聊天|配置模型服务，通过工具操作待办和专注，使用Android系统TTS朗读回复。|
|点子|按日期刷新工作、生活、学习、家庭和关系、自媒体及其他方向的建议。|
|待办|复用已保存的分组和标签，在日历、四象限、分组及状态视图间切换，查看完成任务的标签占比。|
|专注|使用倒计时或秒表，关联待办，暂停与恢复，进入可恢复的全屏计时界面并选择本地上传的背景。|
|生活碎片|记录每天的经历，关联任务进度与已完成的专注时段。|
|教练|探索能力方向，在AI聊天中制定课程提案，进入“每日练习”对话训练，再回到档案回顾。|

待办图表统计完成任务的标签占比，不代表耗时。专注统计记录实际计时时长，结束专注不会自动完成待办。浏览课程也不会被记为掌握。

## 一个念头，连起一天

例如，你想每天读一点书：

1. <strong>先聊清楚。</strong>让AI帮你把目标缩小，通过应用工具创建一条阅读待办。
2. <strong>给它一个位置。</strong>放进已保存的分组，复用标签，用适合自己的任务视图找到它。
3. <strong>留一段时间。</strong>关联这条待办开始专注，选择背景，进入全屏计时。
4. <strong>把经历留下。</strong>在生活碎片里关联已结束的专注时段和任务进度，写下这次的发现。
5. <strong>继续练习成长。</strong>遇到想培养的能力，在聊天中制定课程提案，进入每日练习训练，再到教练档案回顾。

特色就在这些联系中：同一个想法，可以沿着对话、行动、时间和复盘继续走下去。

AI通过应用工具保存任务变更，聊天里说“建好了”不等于任务已保存。AI完成任务需要当前用户明确报告完成；专注时长由计时器记录，不由模型填写。

学习、待办、专注和碎片使用本地存储，各模块有自己的账号与备份规则。发送给模型的消息由你配置的服务商处理。迁移设备前，请检查权限与各模块的备份覆盖范围。

## 从源码构建

<details>
<summary>开发细节</summary>

克隆时同时获取原生依赖子模块：

```bash
git clone --recurse-submodules https://github.com/sherlockerX/Nicholasx.git
cd Nicholasx
```

工具链为JDK21、Android SDK36、NDK27.2.12479018与CMake3.22.1，仓库附带Gradle Wrapper8.11.1。配置工具链后，在Linux或WSL准备原生依赖：

```bash
bash scripts/android/build-natives.sh
```

Windows PowerShell7：

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk21'
$env:ANDROID_HOME = 'C:\path\to\android-sdk'
./scripts/android/Build-Android.ps1 -Target Check
./scripts/android/Build-Android.ps1 -Target Debug
```

原生输入、测试、产物与发布签名见[Android开发指南](../android-development.md)。签名密钥与凭据保存在仓库外。缓存环境上的构建成功不等于新机器构建或真机兼容性验证。

</details>
